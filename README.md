Read All About It — Review App (Scaffold)

This repository is a starter scaffold for your product review app: backend API, web frontend, and mobile guidance.

Workspaces:
- `backend/` — Express API with Socket.IO, affiliate redirect, AI draft endpoint (stub).
- `web/` — Vite + React demo app (Prime-like palette) that connects to backend.
- `mobile/` — Expo instructions to create a mobile app sharing the same backend.

Next steps:
1. Configure `backend/.env` (copy from `.env.example`) and install dependencies.
2. Start the backend and web dev servers and open the frontend.

See each folder's README for commands.
